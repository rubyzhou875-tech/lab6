# CCT360 Lab 6 — Identity V Beginner Guide

Two-page Bootstrap 6 site using the instructor-provided Bootstrap 6 CSS and JS files. Original SVG illustrations are included in `images/`.

## Run locally
Open this folder in VS Code, install **Live Server**, then right-click `index.html` → **Open with Live Server**. Do not open the HTML directly with `file://` because the Bootstrap module needs a local server.
